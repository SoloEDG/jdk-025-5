# 遗迹探勘

安装：`npm install`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18225。

## 光路封门（optics）

在主导航切换到「光路封门」。玩法：移动镜面、分光晶体、遮光石，把持续光源经反射/分裂引到封门前的接光符；同色光在接收器相加，警戒符文收到足够能量则激活陷阱。

设计要点：

- **整体稳态而非帧累计**：以「从每格沿各方向离开的定向光束能量」为变量建立线性系统 `x = T·x + b`，精确分数（bigint `Fraction`）高斯消元求唯一稳态；闭环被方程天然包含，多次回绕后才达标的光不会被截断追踪漏掉。
- **损耗与守恒**：镜面有反射率（损耗 = 1−r）；分光晶体直通与侧路系数之和恒为 1，各路能量总和不超过输入。能量审计逐项核对发射、镜面损耗、墙/遮光石/接收器/门吸收、边界溢出，残差应为 0。
- **无损环识别**：在权重恰为 1 的有向图上跑 Tarjan 强连通分量，检出增益=1 的闭环并指出相关镜片；此时 `(I−T)` 奇异、无有限稳态，依赖它的接收器保持「待定」，绝不开门。
- **阈值零歧义**：阈值一律用精确分数比较，浮点仅作固定点迭代交叉验证（展示偏差），近似误差跨过阈值时仍以精确解求证。
- **颜色隔离**：三色光变量独立、互不串扰，仅同色在接收器相加。
- **证据版本化**：「提交扫描」才冻结当前镜阵（按指纹）的结果；改阵后旧数字保留为观测版本，需重新扫描才更新线索，推断不混算。开门结算每关仅一次，关门重开不重领文物。
- **持久化**：镜阵（含未提交的预览态）与跨关历史证据存于独立 localStorage key，刷新恢复；支持旧版单关存档自动迁移，损坏存档不覆盖并进入恢复模式。

### 测试

测试脚本位于仓库外的独立目录（避免污染应用打包）：

```bash
# 物理求解器：反射、分光守恒、同色相加、闭环叠加、无损环、阈值边界、阻断、颜色隔离
node_modules/.bin/esbuild ../optics-tests/solver.test.ts --bundle --platform=node --format=esm --outfile=/tmp/solver.mjs && node /tmp/solver.mjs
# 状态/持久化：证据冻结、单次结算、多关隔离、刷新恢复、旧档迁移、损坏恢复
node_modules/.bin/esbuild ../optics-tests/state.test.ts --bundle --platform=node --format=esm --outfile=/tmp/state.mjs && node /tmp/state.mjs
```
